# 録音の単語時刻と聞き直し

録音詳細の「単語時刻を生成 / 再生成」を押すと、Settingsで選択した導入済みWhisperで録音後の再認識を行います。セッションと他の重い後処理が停止している必要があります。生成中はライブセッションを開始できません。モデルの自動取得やクラウドへの音声送信は行いません。Whisper以外のエンジンは未対応の理由を表示するため、利用時は導入済みのWhisperを選んでください。

元の本文と訳文の下に、再認識した単語を表示します。元本文と異なる場合はその旨を表示します。これはwhisper.cppの実験的なtoken timestampsによる推定値で、元本文の強制アラインメントや精度保証ではありません。英語の分割トークンやUTF-8のbyte断片は結合し、日本語はモデルのトークン単位で表示します。記号は直前の単位にまとめます。語彙上の日本語の「単語」と必ず一致するわけではありません。

単語を押すと、その発話の元の音声laneをアプリ内のプレイヤーで推定開始位置から再生します。詳細画面上部のプレイヤーで一時停止でき、シークバーをクリック・ドラッグすると同じlaneのまま（一時停止中なら一時停止のまま）その位置へ移動します。強調表示はプレイヤーが返した実際の再生位置・lane・再生中フラグに従い、再生位置を含む発話行には左に線が付き、行が変わると表示範囲へスクロールします。再生位置の報告は約120 msごとのため表示には遅延があります。「未整列」は有効な時刻が得られなかった単位で、クリックして架空の位置に移動することはありません。

「字幕の分割 / 結合」で単語間の境界を切り替えると、プレビューと次の出力に反映されます。境界は操作ごとに保存されます。「再認識字幕 words.srt」は、再認識文だけを録音ディレクトリの別ファイルに出力します。訳文を単語間で切ることはありません。未整列の単位を含む字幕は、時刻を再生成するまで出力を拒否します。従来の文字起こしMarkdown/SRT出力も利用できます。再生成すると手動の字幕境界はリセットされます。

単語時刻・字幕境界・出典モデルは録音内の `words.json` に保存します。元の音声・`transcript.jsonl`・話者分離の文字起こしは上書きしません。音声と対象本文・範囲のSHA-256を照合し、変更後の古い単語時刻はエラーとして再生成を求めます。保存・SRT出力は一時ファイルを検証してから公開し、失敗した再生成では既存の完成ファイルを保持します。異常終了で `.words.json.tmp` / `.words.srt.tmp` が残った場合は、アプリと後処理を止めてから、その一時ファイルだけを削除して再試行してください。

長い発話は最大25秒ごとに元の時間軸を保って再認識します。境界付近の認識や時刻には誤差・欠落が生じることがあります。時刻が逆行・重複した単位や実音声の範囲外の単位は未整列として扱い、区間を文字数で等分する補完は行いません。
