# 対面セッションの任意保存

Issue #29。従来ADRの「マイクのみ・録音なし」を更新する。

保存は設定で明示的に有効化する。既定は無効で、旧設定ファイルでも無効となる。
開始前に選択状態を表示し、実行中は録音ディレクトリの状態を表示する。
変更は次の開始から適用される。

保存時はMeetingと同じRecordingTargetを使う。実際に開いたマイクレーンだけを
SessionRecorderへ渡し、既存のセッションクロック、訳文イベント、履歴読み込みを利用する。
micは入力元であり人物の識別ではない。保存しない場合はRecordingTargetを渡さない。
保存失敗時の通知と停止処理は既存conductorに委譲する。

親Issue #20のうち本変更は#29のみ。他のAI機能は実装しない。
既存履歴の閲覧・書き出し経路へ接続する。要約・Q&Aの追加機能は依存Issue側の責務。

手動確認手順: 設定を無効にして対面開始・発話・停止し新規録音がないことを確認。
有効にして同じ操作後に再起動し履歴を開く。mic.wavとmix.wavの長さ、
発話時刻と訳文を確認し、system.wavがないことを確認。
空セッション、書き込み不能の保存先、Meetingと旧履歴も確認する。
実機録音・モデル精度・要約Q&A統合はこの作業では未実測。モデルの新規取得は行わない。
