# 録音の話者名・発言の割当てを修正する

録音詳細の「参加者 · 会議内で名前付け」で自動話者IDを選ぶか、本文の話者ボタンを押すと表示名を入力できます。名前はその会議内だけで使います。自動IDは元のログに残り、同名の参加者を別のIDとして扱います。名前を空欄にすると表示名を解除できます。自動話者がまだない録音では、既存の「話者を判別」から話者分離を行ってください。新たなモデル取得が必要な場合は既存の導入条件が適用されます。

誤った発言だけを変更するときは、その行の「この発言だけ」で話者を選んでください。「未割当」も選択できます。この操作は同じ自動話者の他の発言には影響しません。参加者一覧での名前付けは同じIDの発言全体に反映されます。

時刻ボタンで原音の該当位置を再生できます。「次の未確認を聞く」は未確認の発言へ順に移動して再生し、末尾から先頭へ戻ります。「確認済み」と話者の選択は独立しています。「未確認」に戻しても選んだ話者は残ります。確認は任意で、通常のMarkdown/SRT出力を妨げません。

編集は「話者修正を保存」で保存します。「未保存の変更あり」が出ている間、出力には最後に保存した内容を使います。録音一覧への移動は保存または「変更を破棄して再読込」の後に行ってください。別タブへ移動しても編集中の内容は画面に残りますが、アプリ終了時の自動保存はありません。保存失敗時は内容が画面に残るため、原因を解消して再試行できます。

手動修正は録音ディレクトリの `annotations.json` に保存します。元音声、`transcript.jsonl`、`postprocess/transcript.jsonl` は編集しません。表示とMarkdown/SRT出力には保存した名前・割当てを反映します。sidecarのない従来の録音も読めます。sidecarが壊れている場合はエラーと元の本文を表示し、修復して再読込するまで保存・補正付き出力はできません。既存ファイルを空の内容で上書きしません。

話者分離をやり直すと行IDや自動話者の意味が変わることがあります。修正はlane・原音上の時刻範囲・元本文が完全一致する一意の発言にだけ対応付けます。同じ話者分離結果で数字の行IDだけが変わった場合は修正を保持します。発言が分割されたり再認識で本文・範囲が変わったりした場合、以前の修正は削除せず「再確認が必要な修正」に残します。

RTTMの内容が変わった場合、旧話者分離の名前・割当ては現在のIDへ自動適用しません。RTTMがない場合は自動話者と発言の根拠全体で同様に区別します。旧設定は画面に表示されるので、原音を聞き直し、現在の参加者IDへ名前を設定し、必要な発言を選び直して保存してください。この判定は誤適用を避けるため保守的です。RTTMの改行などの変化でも再確認になる場合があります。

開いている間に別の編集や話者分離が保存された場合は、古い内容での保存を拒否します。画面の変更を控えたうえで「変更を破棄して再読込」から最新の結果を開いてください。
