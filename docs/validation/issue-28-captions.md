# 小型字幕と共有除外の検証

Issue #28。親計画 #20 の会議中の表示を担当する。検索、会議AI、ASR、翻訳エンジンの変更は含まない。既存AppStateの原文・未確定文・翻訳イベントを購読し、他Issueの完成を必要としない。

通常画面の「字幕」で560×260の浮動ウィンドウを開く。起動時はフォーカスを要求しない。タイトルバーで移動し、枠でサイズを調整する。原文/訳文は両方→原文→訳文、文字サイズは22→26→30→18px、表示件数は最新2→3→1件。長文はスクロールできる。隠す/再表示は内容だけを隠すため操作部は残る。閉じた後は通常画面から開き直す。設定は保存しない。複数回押すと複数字幕ウィンドウを開ける。

共有除外は未実装。字幕が共有・録画に映らないという保証はない。共有中は字幕を閉じるか、字幕以外の単一ウィンドウを共有し、相手側で確認する。内容を隠す操作ではウィンドウ自体は残る。

## 再現手順と記録欄

モデルの追加取得は不要。既存モデルがある場合のみ会議を開始し、字幕を開く。未確定文更新、長い原文、遅れて届く訳文、翻訳失敗を確認する。通常画面と内容が一致すること、フォーカスを会議入力欄に置いたまま更新されること、字幕への明示クリック以外で入力・クリックが奪われないことを確認する。

各実行で日時、OSビルド、アプリ版、ディスプレイ構成、Space、共有方式、相手側スクリーンショット/録画ファイル、観察結果を記録する。ローカルプレビューだけで判定しない。
